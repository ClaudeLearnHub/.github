## Developer Tooling and Technical References

- **Claude Code CLI**: Terminal-based automation, tool chaining, and subagent development workflows.
- **Model Context Protocol (MCP)**: Client-host architectures, custom tool servers, and enterprise data connectivity.
- **Prompt Engineering**: Structured outputs (JSON/XML), few-shot prompting, system instructions, and context caching.
- **Agentic Workflows**: ReAct patterns, orchestration loops, and human-in-the-loop safeguards.

## How to Prepare for Your Anthropic Certification

1. **Review Official Blueprints**: Thoroughly examine the functional skill areas and domain weighting for your chosen certification.
2. **Explore Hands-On Code Guides**: Work through the step-by-step technical guides located in each repository's `docs/` folder.
3. **Practice Real Scenarios**: Test your knowledge using the scenario-based question sets in the README of each exam track.
4. **Take Timed Mock Exams**: Validate your readiness with the timed exam simulators and full question explanations available on [ExamsDay](https://examsday.com/).

## Community and Contributions

Claude Learn Hub is an open-source community initiative maintained by developers and cloud practitioners:

- **Report Errors or Updates**: Open an issue if you spot outdated SDK methods, revised Pearson VUE exam domains, or syllabus changes.
- **Submit Practice Questions**: Submit a pull request with new scenario-based practice questions following the standardized template.
- **Ask Questions**: Join the discussions tab in any individual repository to connect with other candidates preparing for their exams.
